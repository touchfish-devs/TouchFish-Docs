# 关于 TouchFish V5

**TouchFish V5** 是 TouchFish 项目的全新一代版本，从底层架构彻底重建，将原本的局域网聊天工具升级为全功能的社交平台服务端。

### 诞生背景


```
在学校机房等断网环境下，传统的 QQ、微信等聊天工具无法使用。TouchFish 应运而生，它只需要局域网就能工作，也可在公网使用。
```

TouchFish 最初诞生于学校机房的断网环境 —— 当 QQ、微信等需要公网的聊天工具无法使用时，TouchFish 只需要局域网就能让同学们畅快聊天。

V5 延续了这一初衷，但不再局限于局域网。全新的客户端-服务端分离架构让你可以在任何地方部署自己的聊天服务器，无论是在机房内网、云服务器~~，还是家里云~~！

### 设计理念（V5）

- **安全** —— RSA-2048 + AES-256 混合加密贯穿通信
- **功能** —— 不只是聊天，论坛、群组、好友、文件共享、公告系统，完整社交平台
- **自托管** —— 数据 101% 由你掌控，无需依赖任何第三方云服务
- **开放** —— 代码开源，协议开放，欢迎社区贡献



### 与 V4 的区别

TouchFish V5 是彻底的重写，而不是简单的升级。V5 的架构、协议、数据库设计都与 V4 完全不同，V5 不兼容 V4 协议。

可见 V5 的目标是成为一个全新的社交平台，而不仅仅是一个聊天工具。
