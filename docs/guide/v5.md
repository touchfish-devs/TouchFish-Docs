# TouchFish V5 开发计划

欢迎了解 TouchFish V5！这是 TouchFish 项目的下一个重大版本。

## 开发状态

TouchFish V5 已经启动开发！我们正在积极开发新功能和改进。

## 已完成

### 后端核心

```
RSA + AES 混合加密通信框架
用户系统与角色权限
JWT 认证、会话管理
实时通信（WebSocket 消息、回执、输入状态、撤回、置顶）
统一通知系统与实时推送
论坛系统
群聊
好友系统
文件存储（SHA-256 去重、引用计数、配额、分块上传、秒传、OSS2）
表情包（也可被称为贴图，逻辑介于 微信/QQ 表情 和 Telegram Stickers）（表情包市场、用户创建与收藏）
公告系统
图片验证码与邮箱验证
忘记密码 / 邮箱重置
详细错误码（detail_error）
频率限制（REST 与 WebSocket 分列）
P2P 通话信令中继与 ICE 服务器下发（RTC/TURN）
MySQL / PostgreSQL 数据库后端（实验性）
```

### 客户端 (`TouchFish Client`)

基于 Flutter 的跨平台客户端（由 TouchFish Astra 迁移而来），正在与后端对接中。

```
登录 / 注册 / 邮箱验证 / 忘记密码（JWT + 旧版认证兼容）
聊天（私聊、群聊、@提及、引用、转发、撤回、全局搜索、草稿）
消息置顶、群聊精华、房间偏好与免打扰
文件上传（分块、秒传、进度、离线缓存）与多媒体播放
表情包（市场、我的表情、最近使用）
论坛（浏览、发帖、评论、附件）
好友与个人资料、多设备会话管理
P2P 语音视频通话
主密码 / 生物识别锁屏
内置浏览器（标签页、书签、历史、搜索引擎切换）
通知（系统通知、应用内通知、免打扰分级）
多开实例、连通性自检、媒体代理、IP 覆盖
多语言（简体中文、English、文言文）
```

### UR 客户端 (`TouchFish UI Remake 2`)

Electron 桌面客户端，基于 Web 技术构建，由 Pztsdy 主导。

目前仍在开发！
